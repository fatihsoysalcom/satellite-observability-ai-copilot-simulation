# Satellite Observability AI Copilot Simulation

This example simulates a satellite's operation, generating metrics (power, temperature, data buffer) and logs (events, warnings). An AI Copilot (simplified rule-based system) continuously observes this data to infer the satellite's internal state and suggest corrective actions. It demonstrates how observability—using structured metrics and detailed logs—enables intelligent, automated decision-making in complex systems like satellite operations.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
